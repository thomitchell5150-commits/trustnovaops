Our approach

TrustNovaOps builds secure, governed AI for regulated environments, and we hold our own website to the same expectations. This page describes how the website itself is protected. It does not describe, and is not a substitute for, the security terms of any customer engagement.

How this website is protected

  • All traffic is served over HTTPS; HTTP Strict Transport Security instructs browsers to use encrypted connections only.
  • Security headers restrict framing, MIME sniffing, browser features and cross-origin access. A Content Security Policy is being introduced in report-only mode before enforcement.
  • Third-party libraries are pinned to specific versions and verified with Subresource Integrity.
  • Interactive demonstrations run entirely in your browser with simulated data; nothing you type into them is sent to our servers.
  • Forms use spam filtering and a honeypot, screen for sensitive data, and never place form content in analytics or URLs.
  • No credentials or secrets are embedded in website code.

What we do not claim

The TrustNovaOps website is a public marketing and demonstration site. It is not a FedRAMP-authorized system, and TrustNovaOps does not claim a FedRAMP authorization, CMMC certification or government Authority to Operate unless one is expressly stated with supporting documentation. Do not submit classified information, CUI, PHI or credentials through this site.

Report a vulnerability

If you believe you have found a security vulnerability in this website, please tell us through the security contact form. Include a description and the steps to reproduce it — but no sensitive data. Please act in good faith: avoid privacy violations, data destruction and service disruption, and give us reasonable time to respond before any disclosure.

A machine-readable policy is published at /.well-known/security.txt.
